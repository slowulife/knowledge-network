# 知识网络 (Knowledge Network)

把零散的知识织成一张网 —— 一款基于 Flutter 的知识图谱整理与复习工具。

## 这是什么

- 用「网络图」的方式整理知识:一个知识点是一个**节点**,知识点之间有**连线**(关系)
- 支持导入 / 导出 YAML 数据包,方便备份、分享、跨设备迁移
- 支持 Windows 和安卓

## 下载安装

点本页面右侧的 **Releases**(发行版)进入下载页,选择最新版本:

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `知识网络_vX.X.X_安装版.exe` | 双击安装 |
| Windows | `知识网络_vX.X.X_Windows.zip` | 绿色版,解压即用 |
| 安卓 | `知识网络_vX.X.X_安卓_*.apk` | 安装到手机(需允许"安装未知来源应用") |

## 快速上手

1. 打开软件
2. 导入一个数据包(示例数据包见仓库 `样例数据包` 文件夹)
3. 浏览节点和关系,开始整理 / 复习你的知识网络

## 项目结构

```
lib/              主要代码(Dart)
android配置/      安卓构建配置
windows配置/      Windows 构建配置
pubspec.yaml      Flutter 依赖声明
```

## 技术栈

- Flutter / Dart
- 依赖:yaml、url_launcher、file_picker
